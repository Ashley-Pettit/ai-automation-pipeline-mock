# AI & Automation Pipeline (mock)

A working mock of a council's AI and automation request pipeline: a Trainer or BA reviews every request first, picks an outcome, and only agent builds and enterprise builds move into a queue.

**Everything here is invented.** The council, requests, people and dollar figures are made up for demonstration.

## Try it

Open the live page: https://ashley-pettit.github.io/ai-automation-pipeline-mock/

- **My tickets** shows what's assigned to you. Switch person with "Viewing as".
- **Opportunities** has the review queue, quick assignment and outcomes, with list, board and map views.
- **Executive**, **Benefits** and **Scoring** cover the summary, the benefit register and a what-if on the scoring weights.

## Saving

Decisions save in your own browser only, so nobody else sees your changes. Use **Import and export > Reset demo data** to start again.

The page is one self-contained file, `index.html`.
